# Defensible Listing Photos

Simple demo page showing before/after examples from a lived-in apartment, with a compliance one-pager.

All five images in this set are classified as **Exempt** (lighting, color, mild declutter only — no structural or property changes).

## Files
- `index.html` — the demo page
- `ab723-compliance-one-pager-first-pass.md` — the audit record for this set

## Images
Before/after pairs are prepared and can be added to the repo as:
- before-living.jpg / after-living.jpg
- before-kitchen.jpg / after-kitchen.jpg
- before-dining.jpg / after-dining.jpg
- before-hallway.jpg / after-hallway.jpg
- before-bathroom.jpg / after-bathroom.jpg

Once the images are in the root of the repo, the page will display them.

## Pages
Enable GitHub Pages on the `main` branch to get a public URL.
